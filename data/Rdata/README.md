# Data Description

## Contents

This directory contains **[Persistence diagrams for Circles and Torus simulations]**.

The generated files include:

* `[npc=100_nset=500torus_pd.Rdata]`: [Persistence diagrams from torus.]
* `[diagrams_for_equal_intensity_simul.Rdata]`: [Persistence diagrams from the equal-intensity-function simulation.]


## How to Generate

Run the following script from the project root:

```bash
[command to run the code]
```

The data are generated by:

```text
[npc=100_nset=500torus_pd.Rdata] <- [../data_generation_toJSON_Torus.R]
[diagrams_for_equal_intensity_simul.Rdata] <- [../../simulations/Equal_intensity_simulation/Equal_intensity_simulation.ipynb]
```

## Output

After running the script, the generated files will be saved in this directory.

> Note: The generated data files are not tracked by Git.
